Fossil Analyzer

data · statistics

A fossil identification tool: enter a bone length and unit, and the engine matches it against a 20-record database to return the closest species with a confidence score, plus a statistics dashboard over the full dataset.

// key features

  • Matching engine scoring bone length against species records
  • Searchable, sortable, filterable fossil database view
  • Aggregate statistics: oldest record, longest specimen, average confidence
  • REST endpoints for search, stats, single-record lookup and analysis

// stack

  • JavaScript
  • Node.js
  • Express
  • REST API
  • JSON data store
